# C_F generated closure and R,H transport: adversarial audit

22 October 2026.

## Mathematical result

For any map f on the actual tagged birth carrier, if f[b(v)]=b(f(v))
holds for every vertex of the finite generated b-closure C(S), then

    f[C(S)] = C(f[S]).

No injectivity, graph map, or order assumption is used here. The
nontrivial inclusion from left to right follows from the finite set
U={v∈C(S): f(v)∈C(f[S])}; complete b-value equality implies U is
b-closed and contains S, so C(S)⊆U. The other inclusion uses the
b-closed image f[C(S)] and minimality of C(f[S]).

If f additionally commutes with the literal first-root operation,
the exact R-values transport. For an injection, root status is
preserved and reflected, proving the *domain* test for partial H
on images of finite sets of vertices. With induced adjacency,
exact transport of the global H-value follows from the existing
finite closed-container theorem.

## Ten hostile referee checks

1. **Surjectivity on function values.** The premise is equality of
   f[b(v)] with b(fv), not a subset inclusion.
2. **Generated-closure minimality.** The reverse inclusion of closure
   images must be proved, not assumed from the forward image being
   closed. The finite preimage U supplies precisely this missing step.
3. **No injectivity in b algebra.** A b-value-preserving map need not
   be injective for its generated closures to commute. Injectivity
   enters only when reflecting root status or finite predimensions.
4. **Literal tags.** The root map is ordinal 0 of the same request,
   rather than a new choice of an isomorphic block.
5. **Root compatibility.** Commutation with rootOf is an explicit
   hypothesis. Its derivation from preserving the paper's admissible
   order on each whole block is not claimed here.
6. **Partial domain.** Root-status reflection requires injectivity,
   and is exactly what is needed to reflect H's finite argument domain
   *within the mapped source*. No enlarged H domain is invented.
7. **Induced graph.** Global d-hull naturality uses an induced map,
   preserving both edges and nonedges. A homomorphism is insufficient.
8. **Finite containers.** For each finite S, the whole C(S) is finite
   and globally d-closed, as is its image by full b-preservation;
   there is no numerical predimension of an infinite subset.
9. **Partial embeddings.** The current Lean map is a total map of
   the birth carrier. The final equivalence for embeddings defined
   only on arbitrary b-closed substructures must still be packaged
   as a source-subtype theorem, preserving all complete function values.
10. **Reverse implication.** The R,H→b direction requires image
    equality of each C(v), the level-preorder top-block formula,
    intrinsic support reconstruction, and induced finite d-hulls.
    None of those is silently folded into this forward theorem.

All checks are internal hostile proof roles, not external human
referees. All five endpoints require full build, exact axiom,
placeholder, and regression CI before receiving GREEN markers.
