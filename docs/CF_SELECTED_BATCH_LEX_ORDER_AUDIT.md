## Adversarial perspectives

1. **Support-order referee.** Strict monotonicity is needed
   only on the selected old source S, not on the whole source
   stage. The old-old reverse implication follows from
   trichotomy; an injective but nonmonotone map would fail.
   Proper-prefix support comparisons are covered by the
   request-code transport theorem.

2. **Fresh-block referee.** The equality of source request
   tags is reflected by equality of transported target
   tags, using the previously verified complete-code
   injectivity. The fresh interval is the exact natural
   Fin order on both sides, with every ordinal value
   preserved by the canonical cast order isomorphism.
   Order-preservation of block sizes alone would not suffice.

3. **Graph referee.** The request key includes the full
   ordered adjacency matrix and hence nonedges. The
   target-tag map preserves this complete code; the
   precise order is not an arbitrary order on abstract
   isomorphism types.

4. **Stage-coherence referee.** The present theorem is for
   the explicit tagged request-lex relation. It does not
   yet identify that relation with the recursively
   inherited stageLinearOrder on actual U_n and U_m.
   The earlier verified stage-order decomposition lemmas
   should supply that identification. Until then, the
   complete finite level lift remains partial.

5. **Lean referee.** The exact endpoint is registered in
   CheckAxioms.lean. Full Lean compilation, standard
   axiom audit, placeholder scan and finite regressions
   are necessary before certification. The theorem
   must not use an arbitrary rank unrelated to the
   support tuple and complete local graph code.

These are role-separated internal adversarial checks, not
reviews by an independent external human referee panel.
