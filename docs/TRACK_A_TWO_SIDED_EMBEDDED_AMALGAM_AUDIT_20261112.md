# Track A — finite two-sided functional amalgamation over arbitrary base embeddings

12 November 2026. Seven internal adversarial referee roles, not external human reviews.

**Claim.** Given two finite canonical C₀ presentations with injectively embedded common base P, agreeing in induced graph and *full named complete unary values* on P, normalize each carrier by its P-part and complementary tail. Apply the already verified finite tagged free-amalgamation theorem. The actual tagged graph on the normalized carriers has induced strong copies of both original graphs, identifies only points in P, has a single canonical minimal-component presentation, and retains BOTH original full canonical unary operations under the embeddings.

1. **Re-coordinatization referee.** The equivalences `splitEquiv i hi` and `splitEquiv j hj` are exact inverse maps from P⊕Tail onto the two original carriers. Verify `eA(i p)=inl p` and `eB(j p)=inl p` pointwise; only equinumerosity of the base is insufficient.
2. **Function-transport referee.** Use `canonicalValue_relabel` for every original vertex, not merely base vertices or immediate back-neighbours. The final conclusion is equality of *whole finite sets* for both embeddings.
3. **Base-compatibility referee.** The original two base functions need only agree after identifying the common P, as explicit full values F(p). No common numerical component rank is assumed. Dropping equality of complete base values would invalidate the tagged theorem even if the induced base graphs agree.
4. **Graph referee.** The actual amalgam K is the free graph of the two normalized factors. The existing `leftAmalgamEmbedding_induced` and `rightAmalgamEmbedding_induced` prove preservation AND reflection of edges; `amalgamEmbeddings_identify_only_base` excludes spurious identifications. Merely preserving positive edges is insufficient.
5. **Predimension referee.** The tagged theorem requires 2-sparsity and empty-or-minimal-strong stages of BOTH factors, and supplies strongness of BOTH factor images in the final graph. Do not weaken these hypotheses or infer them solely from unary closure.
6. **Empty/symmetric referee.** Empty P, potentially empty tails, empty chronological slots, nontrivial automorphisms of P, and different component orders on incomparable base blocks are allowed. A full ordered canonical representative is not chosen; the theorem concerns unordered finite functional age.
7. **Trust/scope referee.** Exact-head dedicated Lean build, the named `#print axioms` endpoint, whole-source placeholder audit, independent finite exhaustive tests, and repository-wide Lean CI must pass before merge. This is a finite theorem and does NOT yet establish countable all-closed-base extension or functional homogeneity. No manuscript GREEN marker is touched.
