# Track B adversarial audit: transport through source and target gaps

8 November 2026. Each section is a distinct mathematical hostile
review role, not an external human referee report.

## Exact proposed result

Suppose s is a finite b-closed C_F source, n≤m, and none of the
represented birth levels of s lie in [n,m). Let e be a map defined
ONLY on the selected stage-n source cut with values in target U_p.
For arbitrary k, define a map of the selected stage-m source cut
into U_(p+k) by precomposing e with the inverse of the canonical
literal source-gap equivalence and postcomposing with the canonical
target old-stage ascent.

This single operation must preserve every component of the
induction invariant:
- complete graph inducedness and reflection of nonedges;
- strictly increasing actual finite-stage order;
- strict d-closedness of the image in ALL of U_(p+k);
- transport ONTO the complete actual finite birth b-value
  for each selected vertex (assuming the old map already
  preserved its full value).

## Adversarial roles

1. **Source-gap referee:** the source equivalence exists only
   when the source has no births in [n,m). A target gap imposes
   no additional source birth-level restriction. The endpoints
   n and m are treated asymmetrically and correctly.
2. **Old-domain referee:** e is NOT extended to all U_n.
   In particular the original ambient U_n may be nonempty
   and both the selected old cut and first target stage empty.
3. **Literal-label referee:** the source equivalence acts
   by the SAME original birth label on every selected vertex;
   target ascent also preserves literal target labels.
   No arbitrary graph-copy isomorphism is used.
4. **Graph referee:** inducedness is reflected through both
   the source birth-labelled graph and target ascent. Neither
   may replace an iff with a positive-edge implication.
5. **Order referee:** source gap preserves/refects the REAL
   inherited stage order, and target ascent does likewise.
   A strict monotone old map thus remains strictly monotone.
6. **Strictness referee:** closure under the transported map
   is established by equality of its ENTIRE finite image
   with the canonical ascent of the old image, followed by
   strict d-closedness transfer. No weak strongness or
   closure only in the selected image is substituted.
7. **Complete functional values referee:** equality of source
   values across the cut equivalence is needed ONTO, not
   merely inclusion. This comes from the candidate theorem
   in PR #370. The target old stage b-value after ascent
   is exactly the canonical preimage (merged PR #349).
8. **No hidden circularity:** the map is assembled from
   the verified stage-cut birth-image equality, source
   gap equivalence and source b-values, and merged target
   ascent lemmas. The full finite unique level-lifting
   theorem is never assumed.
9. **Edge cases:** n=m and k=0 must give the expected
   identity-on-birth-label cut map; empty source is allowed;
   the target need not be nonempty. A source vertex born
   at m is absent from the old stage-m cut.
10. **Scope:** this is the GAP portion of the induction
    only. Existence of new blocks at represented levels
    uses the one-level theorem. Intrinsic uniqueness
    still requires complete target request-code recovery
    and ordinal rigidity.
11. **Kernel:** six exact axiom endpoints are in the
    standalone CheckAxiomsCFTrackBSourceTargetGap.lean.
    Require full Lean CI including build, standard axioms,
    no placeholders and all finite regressions, against
    the integrated parent branch, before a green marker.
12. **Manuscript:** no frozen mathematical text is changed.
    The overall finite unique level-lifting lemma,
    restriction/composition and monoid remain partial.

These are internal adversarial checks, not independent human reviews.
