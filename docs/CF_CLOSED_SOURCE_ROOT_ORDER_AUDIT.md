# Adversarial audit: b-to-R,H transport on arbitrary closed C_F source

22 October 2026

## Statement

For an arbitrary, possibly infinite b-closed source vertex set X,
suppose a map f on the birth carrier preserves complete b(v)
values, induced adjacency, local injectivity, the level preorder
in both directions, and the natural order of each complete fresh
block, **only where the source vertices lie in X**.

Then f transports every full R(v)-value, every full H(S)-value on
finite S⊆X, and preserves and reflects recognition of the finite
partial H-domain. No globally induced extension of the embedding
of X is required.

## Eleven hostile mathematical checks

1. **Source-only hypotheses:** Nothing is assumed about the action
   of f outside X. This is weaker than the global theorem #211.
2. **Infinite closed source:** To transport C(v), its finite
   generated b-closure is contained in X by the finite-cut
   closure theorem; no predimension is assigned to X.
3. **Full target block:** Complete image equality for C(v) and
   preservation/reflection of birth-level equality produce exact
   image equality for the entire block B(v), not merely inclusion.
4. **Level preorder:** Reflection is essential for pulling a
   target top-level vertex back into the source top block.
5. **Fresh order:** Only strict Fin ordinals within a whole tagged
   block are compared; no arbitrary order on unrelated request
   tags is introduced.
6. **First root:** The first vertex is the unique ordinal-zero
   element of the literal block; order preservation plus whole
   block image equality forces its image to be the target root.
7. **Root reflection:** The converse first-root condition uses
   injectivity *only on X*. The source root is itself in X because
   X is b-closed.
8. **Complete R values:** Every root of a block met by C(v) is
   mapped onto the corresponding target root. No root-set
   equivalence relation is required.
9. **Full H values:** The generic finite restricted induced-hull
   theorem and global finite container closure yield whole-image
   H-value equality under the local induced assumptions on X.
10. **Partial domains:** Domain equality is only asserted for
    image finite subsets arising from the source; there is no
    claim that f is surjective on all ambient roots.
11. **Embedding formulation:** The current f is a total function
    on the carrier whose hypotheses are source-local. Translating
    this into the literal subtype map of an arbitrary embedding
    is the final API step. The reverse R,H→b implication under
    similarly local hypotheses is still separate.

The proofs are audited by these independent internal hostile
mathematical roles, not external referees. Eight theorem
endpoints require full CI and exact axiom/placeholder checks.
