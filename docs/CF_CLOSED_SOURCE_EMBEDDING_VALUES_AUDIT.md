# Adversarial audit: complete b/R,H embedding values on arbitrary closed sources

22 October 2026

## Target theorem

For an arbitrary b-closed source subset X of the actual countable
C_F birth graph, suppose f preserves and reflects adjacency and
the birth-level preorder, is injective, and preserves the natural
ordinal order of every block, with *all hypotheses restricted to X*.

Then complete b-value preservation on X is equivalent to complete
R(v)-value preservation, complete defined H(S)-value preservation
on finite root sets S⊆X, and preservation/reflection of the
partial H-domain on the image of finite source subsets.

The theorem is not an assertion that f extends to an induced
self-map of the whole countable graph. Values of f outside X are
arbitrary and unused in all proofs.

## Twelve independent hostile mathematical checks

1. **Exact C images:** H(R(v))=C(v) and full R/H value preservation
   give f[C(v)]=C(fv). Both finite value equalities are required;
   no homomorphism inclusion can replace either.
2. **R(v) stays in source:** For v∈X, the generated C(v) lies in
   X by b-closedness. Thus the R(v) argument of the partial H
   operation lies entirely in X and consists of genuine roots.
3. **Top-block recovery:** B(v) is the *entire* part of C(v) born
   at the level of v. Reflected equality of birth levels is needed
   for the reverse inclusion in f[B(v)]=B(fv).
4. **Complete difference:** The image of C(v)\B(v) is the
   difference of the images only under injectivity on C(v), a
   subset of X. No global injectivity is assumed.
5. **Old neighbours:** Exact whole-block neighbour transport uses
   induced adjacency only on the finite C(v), which contains
   all source endpoints in the computation.
6. **Strict d-closed hull:** The named support is the finite d-hull
   inside C(v) of those old neighbours. The restricted induced
   hull transport lemma is applied to the same finite container.
7. **Full support equality:** Transport preserves all support
   vertices forced by d-closure, not just directly adjacent ones.
8. **Complete b-values:** b(v)=P_B∪B, so exact images of P_B and B
   imply equality of the complete set-valued function values.
9. **Partial H-domain:** Source-root status and its image are
   preserved and reflected by the forward theorem, using the
   order of complete finite blocks. On the reverse side, domain
   reflection remains an explicit part of the R,H-value
   preservation predicate.
10. **Empty source:** For X=∅ all value conditions are vacuous.
    The theorem does not use any chosen base vertex or default map.
11. **Non-surjective embedding:** f need not be surjective on
    the countable target. Complete values at the image of source
    vertices are nevertheless mapped onto exactly their
    prescribed target values, as required for functional
    embeddings of closed structures.
12. **Literal subtype:** The formal f has a total ambient function
    type, but every assumption and calculation is restricted to X.
    A final wrapper for maps whose literal type is {v //v∈X}
    can use only those restrictions; it must not postulate a
    globally induced extension.

These are role-separated internal adversarial mathematical checks,
not independent external human referees. Exact axiom checks and
a complete integrated build must pass before the full value theorem
is promoted. A separate bridge to the manuscript's actual
