# Track B: adversarial audit of the genuine next-stage cut embedding

1 November 2026. These are independent internal referee roles,
not independent outside mathematical referees.

## Result and exact prerequisites

A finite b-closed set of actual birth-labelled C_F vertices has a
literal next-stage cut. The selected-cut equivalence identifies it
with the old selected subtype together with *all* fresh ordinals
of *all* selected request tags. Composing the inverse equivalence
with the certified genuinely partial selected-batch map produces a
function on the **actual next-stage source cut**.

The five exact endpoints checked here prove:
- inverse equivalence returns the actual literal tagged vertex;
- the resulting map is induced (edges and nonedges);
- it preserves/refects the inherited finite-stage strict order;
- its image is exactly that of the simultaneous partial batch map;
- this image is strictly d-closed in the entire target successor stage.

The hypotheses include an induced strictly increasing old-source map,
a valid support transport certificate, and strict d-closedness of its
old image in the full target old stage. The latter is NOT inferred
from inducedness.

## Adversarial checks

1. **Literal source:** the source domain is the actual selected
   stage cut, with no renamed copy and no arbitrary bijection.
2. **No forbidden totalization:** the old map is defined only
   on the selected old cut. It may map an empty cut into the
   empty first target stage, while the ambient original old
   source stage is nonempty.
3. **All blocks:** the equivalence is surjective only because
   the source is b-closed and each met block is whole.
4. **Induced nonedges:** different tagged blocks are known to
   have no edges between them; the map is induced, not just
   a graph homomorphism.
5. **Order:** the result uses the actual canonical successor
   stageLinearOrder of the source and target, including
   earlier target levels, and makes no separation assumption.
6. **Strict closure:** the image is d-closed in the entire
   target stage, using the selected full-image theorem;
   closure in the partial union alone would not be sufficient.
7. **Value transport:** these particular endpoints do not
   yet identify all auxiliary b-values on the literal cut.
   The separate all-vertex theorem is verified on its own
   selected carrier in PR #289; it must be transported through
   the same equivalence.
8. **Uniqueness and iteration:** a single canonical map is
   constructed here. Uniqueness of an arbitrary functional
   embedding and the induction over represented levels
   remain separate. No monoid identification is claimed.
9. **Kernel:** five exact axiom endpoint checks are listed.
   Do not mark green or merge until full CI succeeds.
