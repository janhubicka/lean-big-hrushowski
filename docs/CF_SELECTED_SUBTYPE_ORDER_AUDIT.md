# Adversarial audit: exact request order under a partial old map

30 October 2026

## Scope

The generic selected-batch map uses e:S→V, where S is the old
source subtype and V may be empty. The exact one-level order is
old vertices first, followed by request tags compared by
the literal sorted support tuple, fresh size and complete
ordered local adjacency matrix, and finally the natural
ordinal within each block.

The theorem proves this strict comparison preserved and reflected
under four explicit hypotheses: e is strictly increasing on S;
T is injective on literal selected request tags; T preserves
and reflects the complete request-lex order; and each finite
ordinal map preserves its actual numerical value.

## Hostile mathematical checks

1. **Empty target:** No total U→V map is introduced. If S=V=∅,
   the old-old comparison is vacuous, while the request
   comparison and fresh ordinals still make sense.

2. **Old order:** Strict monotonicity of e on S implies
   order reflection by trichotomy of the source subtype.
   Mere injectivity would not be enough.

3. **Request order:** The generic theorem deliberately
   assumes an exact biconditional on request comparisons,
   rather than claiming that arbitrary injective tag maps
   preserve an order. This assumption must later be proved
   for the genuinely partial target-request constructor.

4. **Fresh positions:** Internal ordinal equality is required.
   Equality of block sizes alone does not ensure that a
   chosen ordinal map preserves the prescribed order.

5. **Kernel and scope:** The new exact axiom endpoint must
   pass the full Lean build, standard-axiom audit,
   placeholder scan and finite regressions. The theorem
   uses the explicit tagged-lex relation; agreement with
   actual inherited stage orders is a separate verified
   theorem for the full stage tower, to be applied later
   to the genuinely partial map. Finite unique level
   lifting remains unverified.

These are separate adversarial mathematical checks within
the project, not independent external human referee reports.
