# Track E: adversarial audit of natural finite-observation topology (15 Nov 2026)

## Precise theorem

Let V be the actual countable C_F birth carrier and let sigma(v) denote
the **entire** generated b-support in birth-level coordinates. For
S subset N define U[S] = {v in V : sigma(v) subset S}. Assume every
birth level n has an empty-old-support request, hence a vertex z_n with
sigma(z_n)={n}.

For arbitrary sequences S_i subset N and an arbitrary target T subset N,
the following are equivalent:

(a) For each m, eventually S_i and T agree on [0,m).

(b) For each m, eventually U[S_i] and U[T] agree on the *entire actual*
finite birth stage V_{<m}.

The new Lean theorem is a direct two-way application of the already
merged `birthLevelDomain_agree_on_stage_iff` (#571). No copy embedding,
countable lift, Ramsey space, or new finite uniqueness is used.

## Referee challenges (independent proof roles, not external reviewers)

1. **Full-support referee:** Replacing sigma(v) by its own birth level
   invalidates the claimed b-closed copy interpretation. The proof
   uses the existing full-support theorem.
2. **Detector referee:** Reverse continuity requires one z_n with
   sigma(z_n)={n}. A fresh block need not be a singleton vertex.
3. **Quantifier referee:** The eventual index N is allowed to depend
   on finite stage m but not on a vertex v within V_{<m}.
   The proof keeps exactly this quantifier order.
4. **Finiteness referee:** Finite stage observations cover all actual
   vertices born before m, not a chosen bounded collection of test
   vertices.
5. **Limit referee:** The target T need not be infinite, nor any S_i.
   Restriction to copy-domain points is a corollary, not a hidden axiom.
6. **Topology referee:** Agreement of finite observations identifies
   sequential convergence for natural product/metric topologies. It
   does *not* say that the finer Ellentuck neighborhood topology is
   the same topology.
7. **Closedness referee:** The collection of actual infinite copy
   domains need not be closed inside 2^V. For example, increasing
   level ranges S_i={n:n>=i} are infinite but U[S_i] converges to
   the empty domain. This is compatible with Tychonoff closedness
   of the **approximation-code image**, which is a different assertion.
8. **Scope referee:** A point-equivalence with the ordered R/H
   copy-domain family still depends on PR #567; this module does not
   silently generalize to an unnamed reduct, R_0, or rational R_F.
9. **Trust referee:** This branch has not been kernel-verified until
   exact-head Lean compilation, the #print axioms check, and a
   repository-wide placeholder audit have passed.
