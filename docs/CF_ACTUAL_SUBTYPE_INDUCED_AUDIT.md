## Exact claim

Under an increasing prescribed old map e:S→V, with induced
adjacency on S, each selected source request has its actual
transported target request over the literal image of its support.
The actual simultaneous batch map sends all selected blocks to
the same target level and preserves/refects the complete graph

## Hostile proof checks

1. **Empty target.** The old source S and target old stage V
   may be empty even if U is not. No total map U→V,
   distinguished target vertex or nonempty hypothesis is
   introduced. Requests over the empty support retain
   their fresh local graph and are valid target tags.

2. **Old/fresh boundary.** The source old-to-fresh edge
   exists exactly when an old vertex u belongs to the
   source block's literal support and the local graph
   records the edge. The target condition is equivalent
   under the genuine partial support equivalence.
   Reverse implication uses injectivity of e on S to
   exclude a spurious edge outside the support.

3. **Fresh/fresh comparisons.** The target local graph
   is the named-base pullback with the fresh Fin interval
   fixed. All edges and nonedges internal to a block are
   preserved. Distinct fresh request blocks remain
   nonadjacent by actual tagged batch construction,
   and the target request tag map is injective.

4. **Predimension assumptions.** Every transported support
   is d-closed in the target old graph by an explicit
   premise; the old image's own d-closedness is needed
   separately for full-level image closure. The inducedness
   theorem itself does not derive these from order.

5. **Scope and kernel.** Three exact axiom endpoints are
   registered. The full Lean build, standard axiom audit,
   placeholder scan and finite regressions must pass on
   the combined branch before promoting the result.
   This result establishes graph inducedness only; exact
   inherited stage order, complete b-values on new blocks,
   and induction through represented levels remain open.

The checks are distinct internal adversarial mathematical
roles, not independent human referee reports.
