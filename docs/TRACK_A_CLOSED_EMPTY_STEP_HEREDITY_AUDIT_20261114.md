# Track A — closed finite heredity with empty canonical component slots
14 November 2026

This records seven distinct adversarial mathematical review roles, not independent human referees.

**Claim.** If a finite graph G has a component index κ:V→Fin n such that every step is *empty or minimal strong*, then every finite subset s closed under the **entire** canonical unary function inherits the restricted index κ|s with the same empty-or-minimal-strong property in the induced graph. For each u∈s the complete canonical value in the induced graph maps under the literal inclusion **exactly** onto its original canonical value, not merely a subset.

1. **Empty-slot referee.** The pre-existing restriction theorem `canonicalValue_restrict_minimalSteps` quantifies minimal strongness at *all* k<n. It could not be applied to κ with unused levels. The new case split treats equality of consecutive cuts by actual equality of their literal images, and uses the minimal single-step argument only when a nonempty minimal increment exists. In particular, κ need not be surjective.
2. **Predimension referee.** For nonempty slots, the proof uses the certified no-cross closed-substructure lemma and `minimalStrongStep_image_iff` to compare predimensions of the original ambient graph and the induced subtype. The result is not asserted for arbitrary reflexive/transitive unary functions without canonical graph hypotheses.
3. **Complete-value referee.** The inherited full value is proved by the existing `canonicalValue_restrict_image` reachability theorem. Restriction of immediate old-neighbour sets alone would not suffice: all earlier reachable components must survive, which is guaranteed by *complete* unary closedness.
4. **Proof-reuse referee.** Instead of duplicating the long minimal-strong no-cross argument, the old uniform `canonicalValue_closed_cut_step` and `canonicalValue_restrict_minimalSteps` are refactored as one-line wrappers around new single-step lemmas. Their theorem statements, names and import interfaces are unchanged. Any Lean downstream failure must be repaired rather than waived.
5. **Boundary referee.** The finite empty subset and indices with n=0 are permitted, because the resulting subtype may be empty and all quantified stage requirements become vacuous. If κ has an empty old slot, its restriction cannot create a new vertex in that slot.
6. **Independent adversarial falsification referee.** Enumerate all simple graphs on at most four labelled vertices and all index maps into finite ordinals up to n+1 (including unused levels). Retain only valid empty-or-minimal-strong sequences. For every *complete-C-closed* finite subset, check inherited full value equality and all induced empty-or-minimal-strong cuts. A nonclosed subset with a lost predecessor supplies a negative control. The regression is not a proof of the general theorem.
7. **Formal trust and scope referee.** Require an exact-head isolated `lake build`, `#print axioms` on all six new and refactored named endpoints, absence of `sorry`/placeholders, and full repository-wide Lean CI before merge. Nothing is changed in the manuscript TeX or its GREEN validation markers. The result proves finite age heredity; the still separate uniform ordered representative convention of the Ramsey expansion does not follow.

**Potential falsifier:** a nonempty level whose old prefix is not strong can invalidate the conclusion even if the unary algebra is reflexive and transitive. The hypothesis remains genuine empty-or-minimal-strong canonical presentation, without any relaxation.
