# Adversarial audit — naturality of finite global H-values

20 October 2026

**Result.** In any countable finite strict d-closed exhaustion, the least globally d-closed hull of a finite S is the finite d-hull computed inside any finite globally d-closed container T⊇S, not only the specific exhaustion stages. In the actual C_F birth graph, for a finite b-closed T and an induced injection f with b-closed image f[T], every S⊆T satisfies the exact equality f[H(S)]=H(f[S]).

1. **Finite-container referee:** A globally closed set T computes the same least hull as the exhaustion; the proof checks both inclusions using d-closedness within T and global leastness. An arbitrary finite induced T would not suffice.
2. **Strict referee:** Both T and its image must be globally **strictly** d-closed; weak self-sufficiency is not silently substituted.
3. **Nonedge referee:** The finite dClosedHull_image theorem requires a complete induced adjacency iff for f, not just a graph homomorphism.
4. **Image referee:** Reindexing an entire finite ambient d-closed interval through an injection is exact: f[d-hull_T S] equals d-hull_(f[T]) f[S], not only a subset.
5. **Actual carrier referee:** f is a self-map of the existing countable birth-labelled carrier, not an auxiliary split-copy map or a quotient.
6. **b-closure referee:** Closure of f[T] is an explicit premise. Proving it from preservation of every complete b(v)-value is a separate straightforward lemma, and should not be assumed for arbitrary induced graph maps.
7. **Partial domain referee:** The result holds for every finite S (a stronger mathematical fact), but H is only declared in the language on finite *root* subsets. No enlargement of its partial-function domain is claimed.
8. **Substructures vs embeddings referee:** The theorem supplies the exact finite H-value transport for the b→(R,H) embedding direction but does not by itself establish root-status reflection or preservation of b-values from (R,H).
9. **Kernel referee:** Exact declarations are listed in CheckAxioms. CI must compile the new module, inspect axioms and placeholder scan, and complete all regressions before promoting anything.
